# **App Name**: AgriAssist

## Core Features:

- Soil Data Input: Allow farmers to input soil features (Nitrogen, Phosphorus, Potassium levels, pH, moisture) and environmental parameters (temperature, rainfall, humidity) via a user-friendly interface.
- Crop Recommendation: Recommend suitable crops for cultivation based on the inputted soil and environmental conditions, using a trained machine learning model tool.
- Fertilizer Suggestion: Suggest the required amount and type of fertilizer (Nitrogen, Phosphorus, Potassium-based) to balance soil nutrients based on soil nutrient levels and selected crop type, using a trained machine learning model tool.
- Data Visualization: Provide data visualizations for soil nutrient balance to help farmers understand the soil composition and nutrient levels.
- User Authentication: Secure user accounts to store and manage soil data and recommendations.
- Data Storage: Store user input data, crop recommendations, and fertilizer suggestions in Firestore for future analysis and monitoring.

## Style Guidelines:

- Primary color: Earthy green (#6B8E23) to reflect agriculture and nature.
- Background color: Light beige (#F5F5DC), a desaturated version of the primary, for a clean, natural feel.
- Accent color: Warm orange (#D2691E), analogous to the primary, to highlight important information.
- Body and headline font: 'PT Sans' (sans-serif) for a modern and readable interface.
- Use agriculture-related icons, such as plants, fertilizers, and soil, to enhance user experience.
- Clean and intuitive layout with input forms on one side and results/visualizations on the other.
- Subtle transitions and animations when displaying recommendations and data updates.
